# GitHub Profile Action Plan

Use this as the checklist for turning the profile from basic to interview-ready.

## 1. Profile Setup

- Create a public repository named exactly `jibitesh-auth`.
- Put the profile `README.md` in that repository.
- Add a clear headline to the GitHub bio:
  - `B.Tech student | AI/ML | Generative AI | DSA | System Design`
- Keep location, email, and LinkedIn visible.
- Use a clean profile photo where the face is clear at small size.

## 2. Pin Strategy

Pin repositories that prove different strengths:

| Pin | Purpose |
| --- | --- |
| `GemmaX_ChatCore` | AI/ML and generative AI interest |
| DSA repository | Algorithms, consistency, fundamentals |
| Full-stack or backend project | Engineering and system design ability |
| ML project with evaluation | Practical machine learning discipline |
| C++ or systems project | Low-level thinking and programming range |
| Portfolio website | Communication, polish, and presentation |

## 3. README Standard For Every Serious Repo

Each important repository should include:

- One-line project summary.
- Problem statement.
- Features.
- Tech stack.
- Architecture or workflow diagram.
- Setup instructions.
- Screenshots or demo GIF.
- Example output.
- What you learned.
- Future improvements.

## 4. Contribution Habit

- Make small meaningful commits 4-5 days per week.
- Avoid empty commits just to fill the graph.
- Prefer visible progress:
  - README improvements.
  - Tests.
  - Refactors.
  - New examples.
  - Issues and project boards.

## 5. Project Quality Bar

Before pinning a repository, check:

- It runs from the README instructions.
- File names are clean and consistent.
- Secrets, API keys, datasets, and large files are not committed.
- There is no dead code or notebook clutter.
- The README explains the project to a recruiter in under 60 seconds.
